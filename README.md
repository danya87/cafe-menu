# Лабораторна робота №1

## Варіант

**5 — Меню кафе**

## Призначення програми

Консольна Java-програма читає записи меню кафе з текстового UTF-8 файла, перевіряє коректність кожного запису, пропускає помилкові рядки з повідомленням про номер рядка та причину помилки, обчислює підсумкові показники та формує звіт.

Результат виводиться у консоль та записується у текстовий файл.

## Формат вхідних даних

Кожний рядок має формат:

```text
name;category;price;weightG;prepMin
```

де:

- `name` — назва страви або напою;
- `category` — категорія;
- `price` — ціна;
- `weightG` — вага у грамах;
- `prepMin` — час приготування у хвилинах.

Приклад коректного запису:

```text
Борщ український;Основні страви;145.50;350;25
```

Приклад вхідного файла:

```text
Борщ український;Основні страви;145.50;350;25
Капучино;Напої;75.00;250;7
Сирники;Десерти;120.00;220;15
Вареники;Основні страви;помилка;300;20
Лимонад;Напої;60.00;-400;5

Салат овочевий;Закуски;95.00;180
```

Некоректні записи не завершують роботу програми. Для кожного такого рядка виводиться його номер та причина пропуску.

## Результати

Для коректних записів програма обчислює:

- кількість коректних записів;
- середню ціну;
- найбільшу вагу;
- найдовший час приготування.

Для наведеного тестового набору результат:

```text
Меню кафе — варіант 5
Коректних записів: 3
Середня ціна: 113.50
Найбільша вага: 350 г
Найдовший час приготування: 25 хв
```

## Параметри командного рядка

Програма підтримує:

```text
--help
--version
--input <файл>
--output <файл>
```

`--help` — виведення довідки.

`--version` — виведення версії програми.

`--input <файл>` — задає шлях до вхідного UTF-8 файла.

`--output <файл>` — задає шлях до файла звіту.

## Maven

Проєкт використовує Maven Wrapper, тому окрема локальна версія Maven для звичайної роботи з проєктом не потрібна.

На Windows використовується:

```powershell
.\mvnw.cmd
```

На macOS та Ubuntu:

```bash
./mvnw
```

### Запуск тестів

Windows:

```powershell
.\mvnw.cmd test
```

macOS / Ubuntu:

```bash
./mvnw test
```

### Повна перевірка

Команда `verify` виконує компіляцію, JUnit 5 тести, статичний аналіз SpotBugs та пакування програми.

Windows:

```powershell
.\mvnw.cmd clean verify
```

macOS / Ubuntu:

```bash
./mvnw clean verify
```

### Створення виконуваного JAR

Windows:

```powershell
.\mvnw.cmd package
```

macOS / Ubuntu:

```bash
./mvnw package
```

Після успішної збірки створюється:

```text
target/lab01-1.0.0.jar
```

## Запуск JAR

Звичайний запуск:

```powershell
java -jar target/lab01-1.0.0.jar
```

Виведення довідки:

```powershell
java -jar target/lab01-1.0.0.jar --help
```

Виведення версії:

```powershell
java -jar target/lab01-1.0.0.jar --version
```

Поточна версія програми:

```text
1.0.0
```

Явне задання вхідного та вихідного файла:

```powershell
java -jar target/lab01-1.0.0.jar --input data/input.csv --output out/custom-report.txt
```

## Тестування

Для автоматизованого тестування використовується **JUnit 5**.

Тестами перевіряються:

- обробка коректного запису;
- пропуск порожнього рядка;
- неправильна кількість полів;
- нечислове значення;
- від'ємне числове значення;
- порожнє обов'язкове поле;
- ситуація, коли всі записи є некоректними;
- правильність обчислення середньої ціни;
- робота з українським текстом у UTF-8;
- параметр `--version`.

## Статичний аналіз

Для статичного аналізу використовується **SpotBugs**.

SpotBugs запускається автоматично під час Maven-фази:

```text
verify
```

Повна локальна перевірка:

```powershell
.\mvnw.cmd clean verify
```

## GitHub Actions

Для проєкту налаштовано GitHub Actions.

Workflow запускається під час:

- `push`;
- `pull_request`.

Проєкт автоматично перевіряється на:

- Ubuntu;
- Windows;
- macOS.

На кожній операційній системі використовується **Temurin JDK 21** та Maven Wrapper.

CI виконує:

1. checkout репозиторію;
2. встановлення JDK 21;
3. кешування Maven-залежностей;
4. запуск Maven Wrapper;
5. виконання `verify`;
6. запуск JUnit 5 тестів;
7. статичний аналіз SpotBugs;
8. створення виконуваного JAR;
9. публікацію JAR як GitHub Actions artifact.

Після успішного workflow створюються окремі JAR artifacts для Ubuntu, Windows та macOS.
